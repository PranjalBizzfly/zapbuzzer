# ZapBuzzer website

Marketing site for ZapBuzzer, the internal-request CRM for offices. It has 200 statically generated pages built with Next.js 16 (App Router), React 19, TypeScript and Tailwind CSS v4.

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # static generation of all 200 URLs
npm run validate   # content checks: coverage, links, uniqueness, word counts
```

## How it fits together

| Path | What it is |
|---|---|
| `src/content/manifest.ts` | **The list of all 200 URLs**, grouped by cluster, with nav labels. Breadcrumbs, sitemap.xml and the HTML sitemap all come from here. |
| `src/content/pages/*.ts` | Page copy, as typed `PageContent` objects (see `types.ts`). One file per cluster. |
| `src/content/pages/index.ts` | Auto-generated by `scripts/gen-pages-index.mjs` (runs before `dev` and `build`). Don't edit it. |
| `src/content/FACTS.md` | Verified product facts. All copy must stay inside these. |
| `src/content/WRITING.md` | Rules for writing or editing page content. |
| `src/app/[...slug]/page.tsx` | One route renders every non-home page: metadata, canonical, OG and JSON-LD (WebPage, BreadcrumbList, FAQPage). |
| `src/app/page.tsx` | Custom homepage. |
| `src/components/sections/SectionRenderer.tsx` | Renders each section type (prose, workflow, scenario, comparison, metrics…). |
| `src/components/visuals/Visual.tsx` | 16 product-UI mockups in HTML/CSS (dashboard, SLA timer, first-accept-wins…). |
| `src/components/templates/` | Pricing cards, contact form, sign-in/sign-up hand-off, HTML sitemap. |
| `src/lib/nav.ts` / `src/lib/site.ts` | Mega-menu config, and site/app URLs. |
| `src/app/globals.css` | Design tokens (indigo accent `oklch(56% .2 277)`, violet→fuchsia gradient, Inter). |

### Adding or changing a page
1. Add or rename its path in `manifest.ts`.
2. Add a `PageContent` entry in the matching `src/content/pages/*.ts` file.
3. Run `npm run validate` to catch missing pages, broken `related` links and duplicate titles or H1s.

## Open items to confirm before launch
- **Free plan price**: zapbuzzer.com shows "0.04 forever + 40% tax", which looks like a currency-formatting bug. This site shows ₹0.
- **Contact form**: there's no form backend yet, so submitting opens the visitor's email client. Replace this in `ContactForm.tsx`.
- **Sign in / sign up**: these pages hand off to the live app URLs in `src/lib/site.ts`.
- **Enterprise / API pages**: written at the level of purpose and engagement only. No endpoints, event names or certifications are claimed.
- **Assumptions to check**: the Android "App not installed" fix (uninstall first), the emergency-summon disclaimer, and "accepting doesn't stop the SLA clock".
- **Photography**: none yet. Visuals are product mockups. Add licensed images (Indian workplace settings) where they help.
